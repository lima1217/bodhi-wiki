# v1简陋是设计不是缺陷

## 主张

Bodhi v1 的“简陋”是设计选择而非缺陷：v1 是一个**协议浏览器 + 基础协议**，期望开发者在其上长出游戏、社交、文学、视频等内容协议；网站只做协议浏览器，不做别的。早期抱怨“简陋/玩起来不爽”，本质是“赌起来不爽”——但 v1 不是为赌设计的，价格曲线也不适合大市值。

实际发生的：开发者没来 build；唯一落地的具体场景是 **pump.fun**（v1 之后几个月推出的特化版本，市面第一个 memecoin launchpad）。v1 上创建了一万五千条内容，大部分是 meme，有些到过很高的价格。创始人把“最适合 v1 的东西不是 v1 被设计出来的目的”称为一次反讽，并视为核心命题（不知道什么最适合）的一次实证。

## 假设与边界

- “v1 不是为赌设计”是设计意图陈述，不否认 meme/投机是实际主要用法。
- pump.fun 与 Bodhi v1 的关系、时间线需外部核实，不应据此处叙述下定论。
