# 机制演变

## 深读摘要

机制从 Virtual Foundation 到任务/悬赏结构，再简化为 Post 与给币。source-004（创始人问答）补出了前两代被换掉的具体原因，以及“悬赏任务”仍是未实现的规划。

## 三代简述

- **v0 Virtual Foundation**：每 token 带内置金库，持币者投票决定是否用固定数量代币奖励贡献者，像自动 grant。太复杂、有隐患，被换掉。
- **v1 内测任务/悬赏**：任何人发任务、投钱、提交成果领钱。清晰但实操复杂（分钱、有效期、退款无解），做过类似 Moloch DAO 的简化版仍嫌复杂。
- **v2 Post + 给币**：当前在线版本，最简单、最市场化。

创始人同时指出悬赏任务（钱先到、人后认领）仍重要、两种盒子都需要，但目前没有好的实现想法——属未实现规划。
