# 体验优于逻辑

## 定义

Bodhi v2 的方法论转向。原本只打算写一篇长文章去描述“那个东西”，后来意识到这是不对的：

- **“理解”很难**，因为不同的人有完全不同的经历；**“体验”是每个人都有的**。
- 理念的力量不是逻辑，而是体验本身。结构必须通过体验被理解。
- 所以 v2 要做的是一个**“空间”**：人进去之后感受到一种说不清楚、但“不太一样，而且是好的”的东西。
- App 本身要提供完整体验，**不再依赖开发者做任何事**。

## 用法

用于回答“bodhi 该怎么向用户解释自己”“为什么不写一篇完整白皮书”“App 该不该依赖第三方开发者”等问题。它解释了 v2 选择“完整体验型 App”而非“协议 + 期待开发者建生态”的原因，也呼应 v1 开发者没来 build 的教训。
