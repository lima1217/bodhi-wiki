# 领导者与执行者分工

## 定义

创始人借 Cursor 多智能体实验总结出一种分工模式：一个（昂贵的）聪明、有知识、有能力的人负责领导和规划，而一群（便宜的）没那么聪明但能做事的人完成具体工作。Cursor 的实验里，“昂贵模型规划 + 便宜模型执行”的组合用 1/15 的成本达到了与全昂贵组合相近的品质；创始人据此主张，这正是人类社会几千年来默认的协作方式——因为它的成本效益最高，所以中心化的领导者/决策结构几乎不可避免。

## 用法

用来回答“为什么人类组织总是长出中心化领导”“中心化是不是必然的”。它是 Bodhi 要挑战的前提，而不是 Bodhi 要复制的模式。把这条与 [去中心化效率命题] 成对使用：前者是“现状/对照组”，后者是 Bodhi 想验证的“实验组”。

## 证据

- Cursor 实验：不同 agents 组合基于 SQLite 文档用 Rust 重写 SQLite，都完成、品质相近但成本差异巨大：`sources/full_text-20260721.txt:9-13`
- 类比人类协作：昂贵者领导规划、便宜者做事：`sources/full_text-20260721.txt:15`
- 该模式运行几千年的原因是成本效益最高：`sources/full_text-20260721.txt:17`
- 因此中心化决策结构几乎不可避免：`sources/full_text-20260721.txt:21`

## 边界

“Fable 5 花 2 万美金 / Opus 4.8 + Composer 2.5 花 1300 美金 / 品质相近”引自 Cursor 文章，本包未核验原文与图表，属“创始人转述，待核实”。“成本效益最高”“运行几千年”“中心化不可避免”是创始人的归纳与价值判断，不是可证伪的经济结论。本概念描述 Bodhi 要打破的前提，不主张中心化永远最优。
