# 城市代币循环

## 框架

居民或认同者买入城市代币 -> 有人做了让城市更好的事 -> 持币者用城市代币答谢 -> 城市更好、更宜居 -> 代币更值钱 -> 贡献者预期回报更高 -> 更多人愿意贡献。

## 使用场景

- 解释 `$TAIPEI` 这种城市代币为什么不同于普通 meme。
- 判断某个公共群体是否具备代币化基础。
- 讨论 Bodhi 对公共品、城市和地方共同体的意义。
