# 协作结构张力框架

## 框架

把 Bodhi 的总命题组织成一条可复用的“张力轴”，用来判断某个机制/决策是在强化哪一侧、以及它是否服务于“验证去中心化能否高效”这个目标：

1. **现状侧（对照组）** — 中心化领导者/决策结构。证据有两类：人类历史几千年的默认协作方式；Cursor 多智能体实验（昂贵领导者+便宜执行者的成本最优）。结论：因成本效益最高，中心化几乎不可避免。
2. **实验侧（Bodhi 想验证的）** — 借助 crypto，不依赖中心化结构，能否达到类似甚至更高的协作效率。
3. **张力** — Bodhi 不是要否认现状侧的成本优势，而是赌“新技术可以改写这张成本-效率表”，让去中心化结构也能逼近甚至超越。
4. **证据状态** — 实验侧目前只有直觉，没有证据。所以 Bodhi 的每条机制（[行动与给币]、[代币即无工资公司]、[无市长城市]）都应被看成“为验证这个命题而设计的探针”，而不是已成立的结论。

## 使用场景

- 回答“Bodhi 到底在赌什么 / crypto 对 Bodhi 为什么必要”：落到本框架的张力轴。
- 判断一个新机制是否“在 Bodhi 叙事内”：它是否在帮实验侧逼近中心化的协作效率？还是只是在复制中心化？
- 与 [Bodhi 产品叙事框架] 配合：后者给“做什么/不做什么”的取向，本框架给“为什么 crypto、为什么去中心化”的总目标。
- 与 [责任形态演进框架] 区分：后者讲责任边界与股东规模如何沿历史演进；本框架讲中心化↔去中心化的效率张力，是 Bodhi 的顶层动机框架。
